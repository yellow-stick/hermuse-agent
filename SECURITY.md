# Security policy

## Supported versions

Security fixes go into the latest release of Hermuse Agent, the one marked
**Latest** on the [releases page](https://github.com/yellow-stick/hermuse-agent/releases).

## Report a vulnerability

Never report a vulnerability in a public issue, discussion or pull request.
Report it privately, in one of these ways:

- a private security advisory:
  [report a vulnerability](https://github.com/yellow-stick/hermuse-agent/security/advisories/new);
- an email to [contact@yellow-stick.com](mailto:contact@yellow-stick.com).

Say which version and platform are affected, how to reproduce the problem and
what an attacker could do with it. We answer in the advisory or by email, and
publish the advisory once a fixed release is out.

A vulnerability in Hermes Agent itself belongs to
[its project](https://github.com/NousResearch/hermes-agent).
